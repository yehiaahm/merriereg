# MERRIER

Landing page MVP for MERRIER — a streetwear brand launching its Winter Collection ("The New Era").

## Live site

`index.html` is a self-contained static page (no build step, no dependencies) — open it directly or serve it as-is. It's set up to be published with **GitHub Pages** from this repo.

## What's in here

- `index.html` — the production landing page (nav, promo bar, animated dot-mark hero, collection showcase, brand statement, footer).
- `Main.dc.html` / `canvas.json` — source files used for editing the design visually in Claude Design; not needed to run the site.
